1️⃣ Variáveis - Guardando Informações

Uma variável é como uma caixa que guarda informação. Você dá um nome para a caixa e coloca algo dentro.

💡 Pense assim: Uma variável é como uma gaveta na sua casa. Você coloca algo dentro (um valor) e coloca uma etiqueta (um nome) para saber o que tem lá.

📝 Criando Variáveis:

Código Python:
nome = "João"
idade = 25
altura = 1.75
ativo = True

👀 Vendo as Variáveis:

nome "João" (texto)
idade 25 (número inteiro)
altura 1.75 (número decimal)
ativo True (verdadeiro/falso)

🔄 Mudando Variáveis:

Código Python:
idade = 25
print(idade) # Mostra: 25

idade = 26 # Mudou!
print(idade) # Mostra: 26
Resultado:
25
26

✨ Tipos de Dados:

Tipo Exemplo Explicação
str (texto) "João" Texto entre aspas
int (inteiro) 25 Número sem decimal
float (decimal) 1.75 Número com decimal
bool (booleano) True / False Verdadeiro ou Falso
✅ Resumo: Variáveis guardam informações. Você cria uma com = e pode mudar o valor a qualquer momento!

2️⃣ Listas - Guardando Vários Itens

Uma lista é como uma caixa com vários compartimentos. Você coloca vários itens dentro e acessa cada um por sua posição.

💡 Pense assim: Uma lista é como uma fila de pessoas. Cada pessoa tem uma posição (0, 1, 2, 3...). A primeira pessoa está na posição 0!

📝 Criando uma Lista:

Código Python:
frutas = ["maçã", "banana", "laranja", "morango"]

👀 Vendo a Lista:

📋 Lista de Frutas:
🍎 [0] maçã
🍌 [1] banana
🍊 [2] laranja
🍓 [3] morango

🔍 Acessando Itens:

Código Python:
frutas = ["maçã", "banana", "laranja", "morango"]

print(frutas[0]) # Primeira fruta
print(frutas[1]) # Segunda fruta
print(frutas[-1]) # Última fruta
Resultado:
maçã
banana
morango

➕ Adicionando Itens:

Código Python:
frutas = ["maçã", "banana"]
frutas.append("laranja") # Adiciona no final
print(frutas)
Resultado:
["maçã", "banana", "laranja"]

📊 Operações com Listas:

Operação Código Resultado
Contar itens len(frutas) 4
Primeiro item frutas[0] "maçã"
Último item frutas[-1] "morango"
Adicionar frutas.append("uva") Adiciona no final
Remover frutas.remove("maçã") Remove o item
✅ Resumo: Listas guardam vários itens. Cada item tem uma posição (começando em 0). Use append() para adicionar!

3️⃣ Dicionários - Guardando com Nomes

Um dicionário é como um catálogo com chaves e valores. Em vez de usar posição (0, 1, 2), você usa nomes!

💡 Pense assim: Um dicionário é como um telefone. Você não memoriza que João está na posição 5. Você memoriza o nome "João" e liga para ele!

📝 Criando um Dicionário:

Código Python:
pessoa = {
  "nome": "Maria",
  "idade": 30,
  "cidade": "São Paulo",
  "profissão": "Programadora"
}

👀 Vendo o Dicionário:

"nome" "Maria"
"idade" 30
"cidade" "São Paulo"
"profissão" "Programadora"

🔍 Acessando Valores:

Código Python:
pessoa = {"nome": "Maria", "idade": 30}

print(pessoa["nome"]) # Maria
print(pessoa["idade"]) # 30
Resultado:
Maria
30

➕ Adicionando Chaves:

Código Python:
pessoa = {"nome": "Maria"}
pessoa["idade"] = 30 # Adiciona nova chave
print(pessoa)
Resultado:
{"nome": "Maria", "idade": 30}

📊 Diferença: Lista vs Dicionário:

Lista Dicionário
frutas[0] pessoa["nome"]
Usa posição (0, 1, 2...) Usa nome (chave)
["maçã", "banana"] {"nome": "Maria"}
Ordem importa Ordem não importa
✅ Resumo: Dicionários usam nomes (chaves) em vez de posições. Mais fácil de entender e usar!

4️⃣ Loops - Repetir Coisas

Um loop é uma forma de repetir um código várias vezes sem ter que escrever a mesma coisa várias vezes.

💡 Pense assim: Um loop é como um disco tocando. Você coloca a música para tocar e ela toca de novo e de novo até você parar!

📝 Loop com FOR:

Código Python:
for i in range(1, 4):
  print(f"Número: {i}")
Resultado:
Número: 1
Número: 2
Número: 3

👀 Vendo o Loop Passo a Passo:

Passo 1: i = 1 → print("Número: 1")
Passo 2: i = 2 → print("Número: 2")
Passo 3: i = 3 → print("Número: 3")

📝 Loop em uma Lista:

Código Python:
frutas = ["maçã", "banana", "laranja"]

for fruta in frutas:
  print(f"Fruta: {fruta}")
Resultado:
Fruta: maçã
Fruta: banana
Fruta: laranja

🔄 Loop WHILE (enquanto):

Código Python:
numero = 1
while numero <= 3:
  print(f"Número: {numero}")
  numero = numero + 1
Resultado:
Número: 1
Número: 2
Número: 3

📊 Tipos de Loop:

Tipo Quando Usar Exemplo
FOR Quando sabe quantas vezes for i in range(5)
FOR Para cada item de uma lista for item in lista
WHILE Enquanto uma condição é verdadeira while x < 10
✅ Resumo: Loops repetem código. FOR é para listas e números. WHILE é para condições!

5️⃣ Condições - Tomar Decisões

Uma condição é uma forma de tomar decisões no código. "Se isso, faça aquilo. Senão, faça outra coisa."

💡 Pense assim: Uma condição é como um semáforo. Se está vermelho, você para. Se está verde, você vai!

📝 IF (Se):

Código Python:
idade = 25

if idade >= 18:
  print("Você é maior de idade")
Resultado:
Você é maior de idade

📝 IF / ELSE (Se / Senão):

Código Python:
idade = 15

if idade >= 18:
  print("Maior de idade")
else:
  print("Menor de idade")
Resultado:
Menor de idade

📝 IF / ELIF / ELSE (Se / Senão Se / Senão):

Código Python:
nota = 7

if nota >= 9:
  print("Excelente")
elif nota >= 7:
  print("Bom")
elif nota >= 5:
  print("Passou")
else:
  print("Reprovou")
Resultado:
Bom

🔍 Operadores de Comparação:

Operador Significado Exemplo
== Igual if x == 5
!= Diferente if x != 5
> Maior que if x > 5
< Menor que if x < 5
>= Maior ou igual if x >= 5
<= Menor ou igual if x <= 5
✅ Resumo: Condições tomam decisões. IF para uma opção, ELSE para outra, ELIF para mais opções!

6️⃣ Funções - Reutilizar Código

Uma função é um pedaço de código que você reutiliza. Você escreve uma vez e usa várias vezes!

💡 Pense assim: Uma função é como uma receita de bolo. Você escreve a receita uma vez e pode fazer o bolo quantas vezes quiser!

📝 Criando uma Função Simples:

Código Python:
def saudar():
  print("Olá!")

saudar() # Chamando a função
saudar() # Chamando novamente
Resultado:
Olá!
Olá!

📝 Função com Parâmetros:

Código Python:
def saudar(nome):
  print(f"Olá, {nome}!")

saudar("João")
saudar("Maria")
Resultado:
Olá, João!
Olá, Maria!

📝 Função com Retorno:

Código Python:
def somar(a, b):
  resultado = a + b
  return resultado

total = somar(10, 20)
print(f"Total: {total}")
Resultado:
Total: 30

👀 Partes de uma Função:

def - Palavra-chave para criar função
somar - Nome da função
(a, b) - Parâmetros (entradas)
return - O que a função devolve (saída)

📊 Exemplos de Funções:

Função O que faz Exemplo
len() Conta itens len([1,2,3]) = 3
sum() Soma números sum([1,2,3]) = 6
max() Maior valor max([1,5,3]) = 5
min() Menor valor min([1,5,3]) = 1
print() Mostra na tela print("Olá")
✅ Resumo: Funções reutilizam código. Defina com def, use parâmetros, retorne resultados!
