🔑 Como adicionar Secrets no GitHub

1️⃣
Abra seu repositório no GitHub — github.com/usuario/repo
2️⃣
Clique em Settings — aba no topo do repositório
3️⃣
No menu lateral: Secrets and variables → Actions
4️⃣
Clique em New repository secret
5️⃣
Adicione cada secret abaixo

📋 Secrets necessários

🔑
EXPO_TOKEN Obrigatório
Seu token do Expo — gere em: expo.dev/accounts/[usuario]/settings/access-tokens
🔑
GITHUB_TOKEN Automático
Gerado automaticamente pelo GitHub — não precisa criar

🌐 Configurar conta Expo

1️⃣
Acesse expo.dev e crie uma conta gratuita
2️⃣
Vá em Account Settings → Access Tokens
3️⃣
Clique em Create Token — copie o token gerado
4️⃣
Cole como Secret EXPO_TOKEN no GitHub

📋 Passo a Passo Completo

1️⃣
Configure os dados
Aba ⚙️ Configurar — preencha nome da conta e app
2️⃣
Gere os arquivos
Clique em "Gerar Todos os Arquivos"
3️⃣
Baixe o ZIP
Aba 📄 Arquivos Gerados → Baixar ZIP
4️⃣
Extraia na pasta do projeto
Substitua os arquivos existentes
5️⃣
Suba no GitHub
git add . && git commit -m "config eas" && git push
6️⃣
Adicione o EXPO_TOKEN
Settings → Secrets → Actions no GitHub
7️⃣
Dispare o workflow
Actions → Build APK → Run workflow
8️⃣
Baixe o APK
Após ~10min → Actions → clique no build → Artifacts

⚠️ Problemas comuns

❌
Unauthorized / 401
Token inválido ou expirado — gere um novo em expo.dev
❌
Project not found
Nome do projeto ou conta errado no eas.json
❌
webDir does not exist
npm run build não rodou ou gerou em pasta diferente
❌
SDK version mismatch
Versão do Expo SDK incompatível — use a mesma do projeto original
