🔑 Como gerar o EXPO_TOKEN

1️⃣
Acesse expo.dev e faça login
Crie conta grátis se não tiver
2️⃣
Clique no seu avatar → Account Settings
3️⃣
Menu lateral: Access Tokens
4️⃣
Clique em Create Token
Dê um nome ex: "github-actions"
5️⃣
Copie o token — só aparece uma vez!
Começa com: expo_...

🔑 Como adicionar no GitHub

1️⃣
Abra seu repositório no GitHub
2️⃣
Settings → Secrets and variables → Actions
3️⃣
Clique em New repository secret
4️⃣
Name: EXPO_TOKEN
Secret: cole seu token aqui
5️⃣
Clique Add secret

🆔 Como obter o Project ID

1️⃣
Acesse expo.dev → faça login
2️⃣
Clique em Projects → New Project
Ou use um projeto existente
3️⃣
Abra o projeto → Project Settings
4️⃣
Copie o Project ID
Formato: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
5️⃣
Cole no campo "Project ID" na aba ⚙️

📋 Passo a Passo Completo

1️⃣
Crie conta no expo.dev
Grátis — 30 builds/mês
2️⃣
Crie um projeto no expo.dev
Copie o Project ID gerado
3️⃣
Gere um Access Token
expo.dev → Account Settings → Access Tokens
4️⃣
Preencha a aba ⚙️ aqui
Seu usuário, Project ID, nome do app
5️⃣
Gere e baixe o ZIP
Clique em "Gerar Arquivos" → Baixar ZIP
6️⃣
Extraia na pasta do projeto
Substitua app.json, eas.json, etc
7️⃣
Suba no GitHub
git add . && git commit -m "eas config" && git push
8️⃣
Adicione EXPO_TOKEN nos Secrets
GitHub → Settings → Secrets → Actions
9️⃣
Dispare o workflow
Actions → Build APK EAS → Run workflow
🔟
Baixe o APK
~15 min → Actions → build → Artifacts

⚠️ Erros comuns e soluções

❌
Unauthorized / 401
Token inválido → gere novo em expo.dev → Access Tokens
❌
Project not found
Project ID errado → verifique em expo.dev → Project Settings
❌
owner mismatch
O "owner" no app.json deve ser igual ao seu usuário Expo
❌
@workspace não encontrado
Use o arquivo package.json gerado aqui — já corrige isso
❌
metro.config workspaceRoot
Use o metro.config.js gerado aqui — já corrige isso
